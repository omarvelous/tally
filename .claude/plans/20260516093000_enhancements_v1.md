# Tally v2 Delta — Implementation Plan

## Context

The v1 app is feature-complete (all 10 phases shipped). The v2 delta spec (`.claude/specs/20260516093000_enhancements_v1.md`) introduces a new modal logging surface (LogSheet), swipe gestures, screen consolidations, and two new screens (Profile editor, Auth flow). This plan implements all v2 changes against the existing codebase.

**Biggest change:** TaskDetailView (full-screen push) is replaced by LogSheet (bottom-sheet modal with pinned footer controls). This touches TodayScreen, TasksScreen, TaskStatsView, and ContentView.

---

## Phase 1: Foundation — SwipeableRow + Settings Model

**Goal:** Build the swipe gesture primitive needed by both Tasks screen and LogSheet, and extend the settings model for profile fields.

### New: `Tally/Views/Components/SwipeableRow.swift`
- Generic `SwipeableRow<Content: View>` wrapping any row content
- `DragGesture` with 70px threshold, x-axis locked
- Reveals colored pill (configurable label + color) on swipe past threshold
- Props: `pillLabel`, `pillColor`, `threshold`, `onAction`, `disabled`
- Spring animation snap-back on release below threshold

### Modify: `Tally/Models/TallySettings.swift`
Add with defaults (SwiftData auto-migrates):
```swift
var name: String = ""
var email: String = ""
var initials: String = ""
```
Add computed `derivedInitials` (auto-derives from name unless initials manually set).

---

## Phase 2: LogSheet — The Central Change

**Goal:** Replace full-screen TaskDetailView with a bottom-sheet modal managed at the app level.

### New: `Tally/Logic/LogSheetCoordinator.swift`
- `@Observable` class with `logTaskId: String?`, `open(taskId)`, `close()`
- Injected via `.environment()` from ContentView, readable by any screen

### New: `Tally/Views/Components/TaskHeroCard.swift`
- Extract hero card logic from TaskDetailView into reusable view
- Takes `task: TallyTask`, `state: TaskStatus`, renders type-specific display

### New: `Tally/Views/Today/LogSheet.swift`
- Presented as `.sheet` with `.presentationDetents([.fraction(0.95)])` from ContentView
- Layout: ScrollView (hero + entries) + **pinned footer** (log controls, outside ScrollView)
- **Staged input for count/timer:** PresetChipGrid `onTap` writes to `@State stagedValue` instead of committing. Separate LOG button commits. Live preview: "LOG +25"
- **Swipe-to-delete entries:** Each entry wrapped in `SwipeableRow(pillLabel: "DELETE", pillColor: c.neg)`. Release shows `confirmationDialog`. Tap-to-undo removed.
- Reuses: `TaskHeroCard`, `PresetChipGrid`, `describeSchedule()`, `taskStateFor()`, `WidgetCenter.shared.reloadAllTimelines()`

### Modify: `Tally/Views/Components/PresetChipGrid.swift`
- Add optional `selectedValue: Double?` param for visual highlight of staged chip

### Modify: `Tally/Views/Today/TodayScreen.swift`
- Replace `NavigationLink(value: task.id)` with `Button { logCoordinator.open(task.id) }`
- Remove `.navigationDestination(for: String.self)` to TaskDetailView
- Add `@State private var showAddTask` + button in empty state for task creation

### Modify: `Tally/ContentView.swift`
- Add `@State private var logCoordinator = LogSheetCoordinator()`
- Inject via `.environment(logCoordinator)`
- Add `.sheet(item: $logCoordinator.logTaskId)` presenting LogSheet at root level

## Phase 3: Tasks Screen — Swipe-to-Log, Filters, Remove Add Tab

**Goal:** Consolidated task management with active/archived views and swipe-to-log.

### Modify: `Tally/Views/Tasks/TasksScreen.swift`
- Fetch ALL tasks (remove `!$0.archived` filter), filter in-memory by `@State viewFilter: .active | .archived`
- Header: "LIBRARY · N ACTIVE · M ARCHIVED"
- Add filter chips: ACTIVE / ARCHIVED (switches visible list)
- Wrap each active row in `SwipeableRow(pillLabel: "LOG →", pillColor: c.pos)` → opens LogSheet
- Archived rows: 60% opacity, gray pip, tap-only (no swipe), navigates to TaskStatsView for restore
- Footer hint: "TAP TO VIEW · SWIPE LEFT TO LOG" vs "TAP TO REVIEW + RESTORE"

### Modify: `Tally/ContentView.swift`
- Remove Add tab (value: 2) and its `Color.clear` placeholder
- Remove `onChange(of: selectedTab)` intercept hack
- Remove `showAddTask` state and sheet
- 4 tabs: Today(0), Tasks(1), Streak(2), More(3)

---

## Phase 4: TaskStats — MANAGE Section + LOG Button

**Goal:** Add task management actions and quick-log button to stats screen.

### Modify: `Tally/Views/Tasks/TaskStatsView.swift`
- Add `@Environment(LogSheetCoordinator.self)` to open LogSheet
- Toolbar: "+ LOG" button → `logCoordinator.open(taskId)`
- New MANAGE section at bottom:
  - "Edit task" → opens TaskFormView as sheet
  - "Archive task" / "Restore" → toggles `task.archived`
  - "Delete task" (red) → confirmation dialog, deletes task + entries, dismisses
- Reuse delete pattern from ManageTasksView

---

## Phase 5: More Tab — Profile + Auth Screens

**Goal:** Tighten More tab, add profile editor and auth flow screens.

### Modify: `Tally/Views/More/MoreScreen.swift`
- Remove TASKS section (manage/add links)
- Profile card: tappable → opens ProfileEditorView, shows `currentSettings.name` and `derivedInitials`
- Add "PREVIEW · AUTH FLOWS" section: "Sign in / Create account" + "View onboarding" (moved from DATA)

### New: `Tally/Views/More/ProfileEditorView.swift`
- Avatar tile with live initials (accent bg, updates as user types name)
- Name, email (validated), initials override fields
- ACCOUNT section: Change password, Connected accounts, Export data, Delete account (all placeholder/no-op, red styling)
- Sign out button (red, no-op)
- Cancel + Save toolbar buttons

### New: `Tally/Views/More/AuthFlowView.swift`
- Segmented toggle: Sign in / Create account
- SSO buttons: Apple (black) + Google (outlined) — visual only, dismiss on tap
- Email + password fields, show/hide toggle on password
- Sign-up: password strength meter (4-segment colored bar)
- Submit button — visual only, dismisses sheet
- Terms + Privacy footer (sign-up only)
